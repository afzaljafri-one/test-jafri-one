# AskBee AI Chatbot Testing Website

Live testing website for **AskBee** (ZodiacBee AI Chatbot) hosted on GitHub Pages:
👉 **[https://afzaljafri-one.github.io/test-jafri-one/](https://afzaljafri-one.github.io/test-jafri-one/)**

## Application Features
- **Client-Side BM25 / TF-IDF Search**: Sub-millisecond natural language retrieval running directly in the visitor's browser with zero backend dependencies.
- **Complete Knowledge Base**: 368 verified Q&A pairs covering:
  - Vedic Wisdom & Remedies (Kundli, Kundali Match, Sade Sati, Mahadasha, Panchang, Manglik Dosha, Kaal Sarp Dosha, Pitra Dosha)
  - Baby Names (Nakshatra syllables, Moon sign letters, Lo Shu grid, Numerology)
  - Daily Horoscopes, Compatibility & Customer Support
- **UI & Aesthetic**: Metallic Zodiac Gold (`#D4AF37`) & Cosmic Midnight (`#070A13`) theme with AskBee official avatar and branding.
- **Automated Deployment**: GitHub Actions workflow automatically deploys to GitHub Pages on every push to `main`.
